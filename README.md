# Week 3: Advanced Data Analysis and Visualization in Logistics

## Project Overview

This project focuses on analyzing a supply chain dataset using Python to identify logistics trends, evaluate transportation performance, and generate insights for improving operational efficiency.

## Objectives

* Perform exploratory data analysis (EDA).
* Calculate descriptive statistics and correlations.
* Analyze shipping times and transportation costs.
* Examine carrier performance and product sales.
* Create visualizations to communicate key findings.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook / Python scripts

## Dataset

The project uses a supply chain dataset containing 100 records and 37 columns related to logistics and supply chain operations.

## Key Activities

* Inspected and analyzed the dataset.
* Calculated summary statistics and correlations.
* Created six visualizations.
* Identified patterns in shipping times, transportation costs, carrier performance, and product sales.
* Developed recommendations based on the analysis.

## Key Findings

* The dataset contained no missing values or duplicate rows.
* The correlation between shipping cost and shipping time was approximately 0.045, indicating a very weak linear relationship in this dataset.
* Visualizations were used to explore logistics performance and sales patterns.

## Project Files

* `Week_3_Advanced_Logistics_Analysis_Report.docx` — Detailed report with methodology, visualizations, findings, and recommendations.
* `week3_logistics_analysis.py` — Python code used for analysis.
* `supply_chain_clean (1).csv` — Dataset used in the project, if included in this repository.

## Conclusion

This project demonstrates the use of Python-based data analysis and visualization to explore logistics operations and support data-driven decision-making.
